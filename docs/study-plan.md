# 7-Day VHDL Beginner Study Plan

## Day 1: Syntax basics

- Learn `entity` and `architecture`
- Understand `std_logic`
- Write a tiny AND gate
- Compile and simulate it

## Day 2: Testbenches

- Learn how to drive inputs in a testbench
- Use `wait for 10 ns;`
- Verify output values with waveform inspection

## Day 3: Conditional logic

- Learn `if / else`
- Build a basic mux
- Practice `case` statements

## Day 4: Clocked logic

- Learn `process(clk)`
- Learn `rising_edge(clk)`
- Build a D flip-flop

## Day 5: Counters

- Learn `unsigned`
- Build a 4-bit counter
- Simulate the counter waveform

## Day 6: Arithmetic and vectors

- Practice bit-vector operations
- Learn `std_logic_vector` behavior
- Build a small arithmetic example

## Day 7: Mini project

- Build a 7-segment decoder or simple traffic light controller
- Add a testbench
- Verify logic in simulation

## Additional tip

Keep every project small and testable. A 20–80 line VHDL file with a clear simulation is better than a large design you do not understand.
